# 集成HUD（Integrated HUD）

当前版本：**0.6.0 正式版**。通过 **MDL3 加载和启停**，支持武器、FRV、坦克与机甲 HUD 独立开关、武器 HUD 等比例缩放，以及管理器中的狙击枪原生准星安装／恢复选项。数据通过 GameSession 读取；武器部分基于 NarrowHUD 2.0.0 的读取与学习方案，不依赖 HD2 Data Hub 或 Chef Shared Loader。

## 功能

- **武器 HUD**：准星右侧单圆弧显示弹匣余量或热量；弹匣武器下方显示“弹匣内余量 / 备用弹匣量”，热量武器显示百分比，换弹时隐藏武器 HUD。
- **模式与射速**：圆弧右侧显示解析得到的功能模式及射速设置；内置模式采用随包图标，其余已解析模式回退为文字。VG-70 额外显示自动／齐射／全射图标；其他武器不显示普通半自动／全自动，没有有效数据时不显示占位。
- **背包供弹**：读取独立背包对象的剩余量，结合归属及消耗关联；不额外绘制背包面板。
- **乘员探头**：个人武器 HUD 使用同一读取路径，不因乘坐载具而统一隐藏。
- **FRV／坦克 HUD**：显示载具外形、座位占用和当前血量，标记本地玩家座位；FRV 额外显示轮胎状态。
- **机甲 HUD**：统一整体机甲剪影，显示当前总血量，并随血量变化调整颜色。
- **武器 HUD 缩放**：MDL 滑动条调整为 50%–150%，以准星中心为固定锚点整体缩放，载具 HUD 不受影响。
- **原生狙击准星**：管理器提供互斥的开启／关闭选项，为 APW-1、R-40、AMW-20启用原生第三人称准星；安装或恢复后需重启。
- **字体与启停**：数字和文字采用 Monocraft，支持 MDL 实时启停，停用时清理绘制对象与缓存。

武器状态每 0.1 秒整理一次，热量显示在读数之间更新。武器识别综合姿态、携带状态、开火及切枪输入。未知备用量显示“-”；同型武器或背包首次接触可能需要关联学习。圆弧不显示换弹进度。

## 独立开关

在 MDL 的集成HUD详情／设置中分别调整“武器 HUD”“FRV HUD”“坦克 HUD”“机甲 HUD”，默认均开启。标签不再使用可能缺字的全角斜线。更改立即生效，并由 MDL 保存。设置界面附带提示：局内热切换后，可能需要上下车或武器开火刷新状态。武器开关同时控制步行及车内个人武器圆弧；其余三个开关仅控制对应载具界面，关闭一种不影响其他类型。

旧版“载具／机甲 HUD”关闭设置会迁移为三个开关均关闭。所有载具类型关闭时停止共享载具模块；只关闭部分类型时保留共享识别，以便其他类型仍能正常显示。整个模组停用仍会关闭全部界面。

## 武器 HUD 大小

在 MDL 的集成HUD设置中拖动“武器 HUD 大小”：范围 50–150，单位为百分比，步进 5，默认 100。圆弧、数字、图标及间距整体等比例缩放，固定准星中心锚点，载具与机甲 HUD 不受影响。退出设置界面即可看到新尺寸，无需开火刷新。滑动条使用 MDL 内置的 Mod Options Menu 兼容接口保存数值，不需要另装 MOM；若该接口关闭或不可用，则提供同范围的数字调整项。

## 管理器中的狙击枪原生准星选项

安装包最上方为“HUD核心”分组，其中包含“集成HUD”；下方提供独立父选项“狙击枪原生准星”，其下“关闭狙击枪准星（恢复原版）”和“开启狙击枪准星”互斥。HUD本体可独立选择。仅支持本包指定的精确游戏数据版本，已有其他游戏数据修改时拒绝写入。

1. 关闭游戏，在管理器选中相应子选项并部署。
2. 启动游戏，保持“狙击准星安装任务”运行，等待 `%APPDATA%/Arrowhead/Helldivers2/IntegratedHUD-NativeSniper.log` 出现 `SUCCESS`。分帧校验47MB文件，启动后需等待任务完成。
3. 退出并重新启动游戏，让新的武器数据加载。原生准星开启后不依赖武器HUD开关。
4. 关闭或卸载前，选“关闭狙击枪准星（恢复原版）”，同样部署、启动并等待 `SUCCESS`；随后退出、移除选项并重新部署。

任务只接受MDL启动协调器的首次 `loading` 状态，局内重新启用拒绝执行并记录 `DEFERRED`，需要重启。MDL列表可能仍显示这项任务，但其开关不是准星开关：完成后停用任务或HUD均不撤销磁盘修改；校验期间停用会取消未提交任务，需要重新启动后完成。任务启用后不做每帧绘制，完成后停止文件处理。

仅修改APW-1、R-40、AMW-20的准星配置；该底层补丁已由用户实机确认有效且不干扰其他武器。安装／恢复任务已通过离线文件检查，尚无完整流程的实机验证记录。包内仅携带小型差分及校验信息，不包含完整游戏数据、加解密密钥或原生DLL。首次开启会验证并保存原版备份；若已有此前独立安装的已知补丁，可反向重建原版备份。备份为 `%APPDATA%/Arrowhead/Helldivers2/IntegratedHUD-NativeSniper-26251122-original.dl_bin`。不要在完成恢复前删除它。

## 沿用的0.5.5修复

- 每帧核对玩家与当前角色关联；死亡、角色消失或替换时停止姿态读取，并重建武器传感器及单位缓存。
- 模型位置读取前检查对象归属、角色类型与节点数量；姿态读取重新解析动画变量索引。
- 保留车内武器显示、现有载具/机甲HUD及MDL启停行为。保留已有的角色生命周期和模型读取保护。

## 前置与安装

需要 **MDL3**，适配目标为 `3.0.0-dev.21 preview`、Steam Build **26251122**。

MDL3 作者：M!ni$try0fSc!eиce。请前往 [MDL3 官方发布页](https://ayakamods.com/mods/mdl3-preview-%E9%BA%A6%E5%BD%93%E5%8A%B33-%E9%A2%84%E8%A7%88%E7%89%88%EF%BC%81.5710/) 阅读安装说明及条款并下载依赖。本仓库和构建包不附带 MDL3、HD2 Data Hub 或 Chef 加载器。

关闭游戏，停用旧版集成 HUD 和提供重复武器／载具界面的冲突模组，再用支持 MDL 的管理器导入 `IntegratedHUD-MDL-0.6.0.zip` 并部署。保留 MDL3 启用；其他模组需要 HD2 Data Hub 时可继续保留，它不是本模组的前置。首次部署材质后重启游戏。之后可通过 MDL 启停本模组。

本包不覆盖游戏 boot，不调用 FFI，也不需要玩家安装 Python 或外部采样器。

## 构建

需要 Python 3.10+ 和本机合法安装的游戏。Python 及依赖仅用于构建。

```powershell
python -m pip install -r requirements.txt
python tools/build.py --game-root "D:\steam\steamapps\common\Helldivers 2"
```

默认输出到 `dist/`，可使用 `--output-dir` 指定其他目录。构建器核对游戏版本及 PE 指纹，进行 Lua 5.1 编译、有限武器／座位／血量／启停模拟和包体完整性检查；不自动部署，不生成 sha256 侧车文件。`VERIFICATION.json` 中的哈希用于记录构建输入；`runtime_verified=false` 表示构建器自身未运行游戏，它不代表构建器进行过实机测试。

仓库已包含生成后的武器传感器与字体／图标几何，普通构建不需要 NarrowHUD 原始压缩包。重新导入上游源码时，使用合法取得的 NarrowHUD 2.0.0 包运行 `tools/import_narrowhud200.py <压缩包路径>`。重新生成美术数据时，额外安装 `fonttools`、`Pillow` 并运行 `tools/bake_weapon_art.py`。
